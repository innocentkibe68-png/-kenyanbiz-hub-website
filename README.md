# KenyanBiz Hub Website

Professional business website for KenyanBiz Hub - an AI automation agency based in Nairobi, Kenya.

## Overview

This website showcases AI-powered solutions for Kenyan businesses including:
- AI Chatbots (WhatsApp bots, customer service bots, etc.)
- AI Agents (autonomous agents, data processing, workflow automation)
- Website Development (business websites, landing pages, ecommerce)
- WhatsApp Automation (auto-replies, broadcast systems)
- Digital AI Products (templates, prompt packs, automation workflows)

## Features

- Fully responsive design
- Dark theme with purple and teal accents
- Smooth scroll animations
- Mobile-friendly navigation
- WhatsApp integration for instant contact
- SEO optimized
- Fast loading
- No frameworks or build tools (pure HTML/CSS/JS)

## Deployment

This website is ready for deployment on Vercel with zero configuration.

To deploy locally:
1. Clone or download this repository
2. Open `index.html` in your browser

For Vercel deployment:
1. Push this repository to GitHub
2. Import the project in Vercel
3. Vercel will automatically detect the settings and deploy
